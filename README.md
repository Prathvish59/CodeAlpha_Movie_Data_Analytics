\## Project Overview



This project performs an end-to-end data analytics workflow using movie data collected from a public web-scraping practice source.



The workflow includes:

1\. Web scraping

2\. Data cleaning and preparation

3\. Exploratory data analysis

4\. Data visualization

5\. Insight generation



\## Dataset



\- Source: Scrape This Site

\- Years analyzed: 2010–2015

\- Total movies collected: 87

\- Features:

&#x20; - Movie title

&#x20; - Year

&#x20; - Awards

&#x20; - Nominations

&#x20; - Best Picture status

\## Key Findings



\- 2014 and 2015 had the highest number of movies, with 16 movies each.

\- 2012 recorded the highest total awards, with 25.

\- 2012 recorded the highest total nominations, with 75.

\- Gravity received the highest number of awards, with 7 awards and 10 nominations.

\- Awards and nominations had a positive correlation of 0.75.

\- One Best Picture winner was identified for each year from 2010 to 2015.
